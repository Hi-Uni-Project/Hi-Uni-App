## 📱 프로젝트 소개

**Hi-Uni**는 대학생들이 취업 준비와 커리어 개발을 더 효과적으로 할 수 있도록 돕습니다. 같은 대학, 같은 학과의 선배와 동료들이 공유하는 생생한 취업 후기와 정보를 확인하고, 자신의 커리어를 체계적으로 관리할 수 있는 올인원 플랫폼입니다.

<br/>

## 🎯 개발 배경

<div align="center">
  <img src="/src/docs/images/main-1.png" width="250" />
  <p><i>"대학생 커리어 정보, 한 곳에 모으다"</i></p>
</div>

현대 대학생들은 취업 준비 과정에서 다음과 같은 어려움을 겪고 있습니다:

- 📊 **정보의 홍수 속 신뢰할 수 있는 정보 부족**: 인터넷에는 취업 정보가 넘치지만, 나와 비슷한 배경을 가진 사람들의 생생한 경험담을 찾기 어렵습니다.
- 🎓 **학과별 특성을 반영한 맞춤형 정보의 부재**: 전공마다 취업 시장과 준비 과정이 다른데, 이를 고려한 정보를 얻기 힘듭니다.
- 📝 **분산된 커리어 관리**: 이력서, 자기소개서, 일정 등을 여러 곳에서 관리하며 번거로움을 겪습니다.
- 🤝 **대학 커뮤니티의 단절**: 선배들의 경험과 조언을 듣고 싶지만 접점을 찾기 어렵습니다.

**Hi-Uni**는 이러한 문제들을 해결하기 위해 **대학교 이메일 인증 기반의 신뢰할 수 있는 커뮤니티**와 **통합 커리어 관리 시스템**을 제공합니다.

<br/>

## ✨ 핵심 기능

### 1️⃣ 커리어 커뮤니티 (게시판)

<div align="center">
  <img src="/src/docs/images/board-1.png" width="250" />
  <img src="/src/docs/images/board-2.png" width="250" />
  <p><i>"카테고리별로 묻고 나누는 생생한 커리어 정보"</i></p>

**같은 대학, 같은 학과 선배들의 생생한 경험을 공유하세요!**

- 📌 **다양한 카테고리별 후기 공유**
  - 🏢 **취업 후기**: 입사 과정, 준비 방법, 합격 팁
  - 💼 **인턴십 후기**: 실무 경험, 배운 점, 인턴 생활
  - 🎤 **면접 후기**: 질문 내용, 분위기, 답변 전략
  - 👔 **실무 이야기**: 직무별 실제 업무, 필요 역량
  - 📜 **자격증 후기**: 준비 기간, 공부 방법, 합격 노하우

- 🔥 **주간 인기 게시물**: 좋아요 기반 알고리즘으로 트렌딩 정보 확인
- 🔖 **북마크 & 좋아요**: 유용한 정보를 저장하고 공감 표현
- 💬 **댓글 & 대댓글**: 궁금한 점을 직접 물어보고 소통
- 🔍 **검색 & 필터링**: 원하는 정보를 빠르게 찾기

> 💡 **특별한 점**: 후기 작성 시 구조화된 템플릿을 제공하여 중요한 정보를 빠짐없이 기록하고, 다른 학생들이 필요한 정보를 쉽게 찾을 수 있습니다!

### 2️⃣ 통합 커리어 관리 (포트폴리오)

<div align="center">
  <img src="/src/docs/images/career-1.png" width="250" />
  <img src="/src/docs/images/board-4.png" width="250" />
  <p><i>"후기 게시글 작성만으로, 내 이력서와 자기소개서 완성"</i></p>
</div>

**이력서와 자기소개서를 한 곳에서 체계적으로 관리하세요!**

- 📄 **이력서 관리**
  - 프로필 이미지 등록
  - 학력, 경력, 스킬, 수상 경력 등 섹션별 관리
  - 실시간 미리보기로 완성도 확인
  - 후기 게시글 작성 시 자동으로 경력 데이터 축적

- ✍️ **자기소개서 관리**
  - 여러 버전의 자소서 작성 및 저장
  - 초안과 최종본 구분 관리
  - 기업별 맞춤 자소서 작성

- 🤖 **AI 자기소개서 생성 (처음이라면 누구나! 5회 무료)**
  - AI가 자소서 초안을 자동으로 작성
  - 디자이너로 성장하고 싶다면? AI가 맞춤형 자소서 제안
  - 서류 작성의 부담을 줄이고 내용에 집중

> 💡 **특별한 점**: 게시판에 후기를 작성하면 자동으로 내 이력서에 경력이 쌓이고, AI가 이를 기반으로 자기소개서를 작성해줍니다. 모바일에서 언제 어디서나 커리어 문서를 수정하고 관리할 수 있어, PC가 없어도 준비가 가능합니다!

## 🚀 기대 효과

### 💪 신뢰할 수 있는 정보 기반 취업 준비

대학교 이메일 인증을 통해 같은 학교, 같은 학과 선배들의 **검증된 실제 경험**을 공유받을 수 있습니다. 이를 통해 더욱 효과적이고 실질적인 취업 준비가 가능합니다.

### 📈 체계적인 커리어 관리로 효율성 향상

이력서, 자기소개서, 일정을 하나의 플랫폼에서 관리하여 **준비 과정의 혼란을 최소화**하고, 더 많은 시간을 실제 역량 개발에 투자할 수 있습니다.

### 🤝 대학 커뮤니티 활성화

같은 학교, 학과의 학생들이 서로의 경험을 공유하고 조언을 주고받으며 **더 강한 유대감과 네트워크**를 형성합니다. 선배들의 경험이 후배들에게 전달되는 선순환 구조를 만듭니다.

### 🎯 학과 특성을 반영한 맞춤형 정보

전공별로 다른 취업 시장과 준비 과정을 고려한 **맞춤형 정보**를 얻을 수 있어, 자신의 진로에 더 적합한 준비가 가능합니다.

## 🚀 시작하기

### 필수 요구사항

- Node.js >= 18
- React Native CLI
- iOS: Xcode 14+, CocoaPods
- Android: JDK 17+, Android Studio

### 설치 및 실행

```bash
# 저장소 클론
git clone [repository-url]
cd hiuniFE

# 의존성 설치
npm install

# iOS 설정 (iOS만 해당)
cd ios && pod install && cd ..

# 개발 서버 실행
npm start

# iOS 실행
npm run ios

# Android 실행
npm run android
```
